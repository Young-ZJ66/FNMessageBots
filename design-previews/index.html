Swiss Precision

1-swiss.html

瑞士精确：靠排版、栅格与留白建立高级感，零装饰、零阴影、方角。

  • 字号阶梯 + 8px 基准间距
  • 单强调色，深色模式零硬编码颜色
  • 细 1px 分隔线代替卡片分组

Ops Console

2-ops-console.html

运维控制台：颜色只承载状态语义，密度换效率。最贴合「这本来是监控工具」。

  • 左侧导航 + 状态色（严重/警告/正常/进行中）
  • 等宽数字对齐，紧凑行高 + 斑马纹
  • 开关用成功绿，语义一致
打开完整版（可切主题） 深色

Deep OLED

3-deep-oled.html

近黑影院级深色：层级靠 1px 描边，发光只给状态。科技感最强，仅深色。

  • 底色 #020617，卡片靠描边分层
  • 状态点带极轻发光，其余零发光
  • 放弃浅色模式
打开完整版（可切主题） 深色

Calm Cyan

4-calm-cyan.html

冷静青：浅色为底，低饱和青做科技感，柔和两级阴影。最干净体面。

  • 低饱和青 #0891b2 + 大量中性灰压住
  • 柔和阴影 + 1px 描边（不是玻璃态）
  • hover 只改边框与底色，不位移
打开完整版（可切主题） 深色

5-bento.html

  • KPI 数字放大到 56px（hero 卡）
